# Product context

> updated 2026-11-13 · c2c5690

CryptoScroll helps a person handing a temporary secret to a known recipient avoid keeping a plaintext copy in an ordinary message thread. The core job is create, transfer, deliberately read, then stop serving the stored copy.

Primary audience: developers sharing temporary setup credentials with a colleague. Use the full link, and optionally a strong passphrase shared through another channel. No account, draft history, payments or identity profiles are in scope.

The demonstrable capability is that a second browser can open a note without sharing storage with the sender, while the backend holds no decryption keys and authorizes at most one retrieval in one-time mode. This is not a claim of unique market differentiation or audited security.

Value return: an open-source hackathon project and practical demonstration of browser encryption. No monetization is planned. Product copy must disclose the limits of deletion and malicious frontend code rather than promise total anonymity or no trace.
