# Reporting a security issue

Use GitHub's [private report form](https://github.com/sovergarden-dev/cryptoscroll/security/advisories/new) to contact the maintainers. Include the affected revision or deployment date, the behavior you observed, its impact, and the smallest example that uses disposable data. A report can describe an issue without including a working note link.

Keep real note contents, passwords, link fragments, revocation credentials and unredacted network traces off the report. The maintainers will use the private advisory thread for questions, verification and coordinated disclosure.

The [review brief](docs/ref/security-review-brief.md) identifies the published source and dependency locks, the one-time-read guarantee, and the limits of deletion and browser-side encryption.
